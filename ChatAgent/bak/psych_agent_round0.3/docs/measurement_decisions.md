**本轮测量决定与待确认事项**

本文件记录代码为何这样处理数据。规则草案用于验证实现，不代表已建立可靠、有效的心理测量模型。

| 事项 | 本轮决定 | 后续需要的依据 |
|---|---|---|
| 构念方向 | higher/lower描述原变量，不统一改成风险方向 | 测量专家审阅变量定义及维度边界 |

| G01强硬 | 没有具体行为时标为unclear | 身体伤害、坚定表达、自我保护的操作区分 |
| F类背景 | 单独保存，不进入核心变量计分 | 同伴、家庭、教师、学校支持的构念区分 |
| 变量数值 | value和confidence固定为null | 评分锚点、可靠性、效度与校准数据 |

| 安全处置 | 本轮仅合成数据实验，不具备面向学生的安全分流与响应流程 | 将来真实访谈前独立实现并验证停止与安全流程 |
| 风险结果 | risk_result=null，未创建风险规则文件 | 标定标签、独立效标、评估集与概率校准 |
| 后续角色 | 施暴、受害、施暴—受害；不输出旁观者角色风险 | 三类输出定义及相互关系 |

学生没有谈到某一信息，不等于相应特质不存在；对假设问题说出合适做法，也不能证明真实情境一定能做到。当前的方向记录仅针对表达，不用于给学生贴标签。

量表改成情境问答后，其测量解释需要相应依据。《教育与心理测验标准》标准9.9讨论改变形式或施测方式后的测量依据；标准1.0—1.1要求明确分数的用途、对象和构念。[标准原文](https://www.testingstandards.net/uploads/7/6/6/4/76643089/standards_2014edition.pdf)

后续风险判断若涉及实际霸凌事件，还需区分力量不对等、重复或很可能重复发生等信息，不能仅由情绪或攻击意向推定角色。[CDC霸凌定义](https://www.cdc.gov/youth-violence/about/about-bullying.html)
