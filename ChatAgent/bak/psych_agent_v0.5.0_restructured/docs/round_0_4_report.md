# 第3轮代码修改与功能报告：0.5.0

日期：2026-09-09。基线：0.3.0。目标：打通完整的访谈、十变量画像、A4风险计算和A5报告流程；根据本轮要求，将变量置信度暂时固定为1.0，等待后续人工校验。

## 本轮修改

1. 新增 `config_manifest.json`，使用 `CFG_004` 和相对文件路径组织配置集合。
2. 新增证据质量、变量测试计分、固定置信度、A4风险计算和A5报告配置。
3. 将原A4解释职责调整为A5；A4成为独立风险计算Agent。A4不调用LLM猜概率，默认执行确定性的等权测试计算，也保留外部模型适配器。
4. 将higher/lower证据转换为0—1变量流程测试值。十变量权重均为1.0，十变量置信度均固定为1.0；缺失变量的value仍为null。
5. A4输出施暴、受害、施暴—受害三角色的总体测试概率，以及身体、言语、关系三种形式测试概率。保护因素按反向测试作用处理，联合值执行概率关系约束。
6. 全部测试数值增加 `fixed_test_value`、`uncalibrated_flow_test`、`human_review_required` 等标记，A5报告开头强制显示人工复核警告。
7. 从0.4业务快照、任务、画像、风险输入、风险结果和回放中移除哈希字段，改用配置集合编号、对象编号、会话编号和相对文件路径。
8. 更新Agent配置、CLI、schema、五套合成回放、完整示例和运行文档。

## 测试规则说明

变量测试值按不同测量组平均：higher=1，lower=0，同组同时出现higher/lower=0.5，只有unclear或无证据时为null。重复证据不增加组权重。

角色特征全部等权。风险因素使用value，保护因素使用1-value。A4输出字段沿用probability以验证完整产品数据接口，但状态明确为 `test_probability_only`，并不表示这些数值已由真实样本标定。

十变量置信度固定为1.0，包括未观察变量的置信度占位字段。A4有可用特征时角色置信度也固定为1.0；没有特征时角色概率和置信度为null。1.0不代表完全确定。
