# 0.5.0 修改与功能报告：低信息回答不中断访谈

日期：2026-09-12。基线：0.4.1。当前配置集合：`CFG_006`。

## 本轮问题复现与结论

上传运行包在T003提问“你会怎样理解对方刚才的举动？”，被试回答“可能是不小心的”。A3第一次输出已经包含完整观察、槽位、证据和理由，但错误地把当前轮次 `T003` 写入 `context_turn_ids`；第二次修复原样重复，因此0.4.1中断访谈。

这不是回答简略造成的语义缺失，而是A3的引用结构错误。0.5.0将模型格式错误与被试回答质量分开处理，避免把系统失败归因于被试。

## 本轮修改

1. A3先确定性过滤 `context_turn_ids`，只保留同一情境实例中已经完成的轮次。当前轮次、未来轮次、未知轮次、不同情境轮次和重复引用会被删除。
2. 上下文清理不改变观察、原话、槽位、证据规则或理由。以本次T003输出为例，删除错误的 `T003` 后，其余有效观察可正常提交，不需要第二次LLM调用。
3. 若候选仍不合规，保留一次可审计LLM修复。修复后仍不合规则返回协议允许的空观察，不生成或补写任何量表证据，也不终止访谈。
4. 规范化、修复或降级信息独立保存为 `turns/Txxx/a3_diagnostic.json`；原始两次模型响应仍保存在 `llm_calls/a3/`。
5. 目标单元未取得有效槽位或证据时，控制器进入一次 `clarify`，用不同角度重新提问；第二次仍无有效信息就保留该单元为含糊/未完成并推进下一单元。
6. 五个计划的轮次上限增加到可以容纳“每个单元两次提问”的最坏情况。`s01` 即使所有回答都低信息，也能完成开场及八个适用单元共17轮，不会在最后一个单元后被误标为预算终止。
7. 每轮新增独立的 `response_quality` 元数据。回答简略度按去空白后的字符数统计，当前测试阈值为不超过6个字符；明确 `/skip` 不进入简略度分母。
8. 当简略回答比例严格大于50%时，`coverage_report.json`、`profile.json` 和 `report.md` 标注本次画像可能信息不足，同时明确不能据此判断拒绝、欺骗、不配合动机或心理特征。
9. 因访谈策略、预算和报告策略发生变化，建立新配置集合 `CFG_006`。量表题目—变量映射、证据方向、等权测试值及置信度1.0保持不变。

## 已完成功能

- 上传包中的T003错误形状已形成自动化回归测试。
- A3非法上下文引用不会再中断访谈，并尽可能保留可验证内容。
- 任意其他A3结构失败不会伪造证据，也不会因两次失败终止测评。
- 低信息回答最多换角度追问一次，随后正常推进。
- `s01` 在全程低信息回答下仍遍历所有计划内测量单元并正常结束。
- 简略回答、低信息回答、追问安排和A3安全降级分别统计。
- 简略度严格超过50%时报告提示；正好50%不提示。
- 网络失败仍保留回答并暂停，避免自动重复产生费用或重复提交。
- 121项自动化测试全部通过；配置、JSON和完整离线回放检查通过。

## 待完成功能

## 兼容性

公开JSON接口的 `schema_version` 仍为 `0.5.0`，但受管配置已经升级为 `0.5.0/CFG_006`。为防止新旧访谈策略混用，0.4.1产生的 `CFG_004` 会话不能直接续跑；请用0.5.0开始新访谈。旧运行包可继续用于离线审阅。
