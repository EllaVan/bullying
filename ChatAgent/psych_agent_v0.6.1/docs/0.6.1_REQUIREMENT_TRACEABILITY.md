# 0.6.1 需求追踪

本表对应 0.5.2 以来及本轮已提出问题。紧急风险处理、人工复核工作流、隐私权限、缩短对话按要求暂不实现。

| 已提出问题 | 本版处理 | 验证位置 |
|---|---|---|
| 覆盖即满分、缺少强度 | 方向×Likert强度×框架默认强度；冲突软消解后满分计入 | `conflict_resolver.py`、`variable_scoring.json`、冲突测试 |
| 冲突剔除导致剩余面极端化 | `resolved_conflict` + 原因/证据原文审计；不降计分权重 | `facets.py`、报告 §8 |
| 缺旁观角色 | 四角色独立分数含 `bystander` | `risk_scoring.json`、`risk_engine.py` |
| 评估需纳入真实霸凌量表思想 | 锚定包 `olweus_dbvs_bpbq_v1` + `scale_constraints` 门控 | `SCALE_RULES_SOURCE.md`、`scale_gates.py` |
| 报告过工程化、证据为 hash | `evidence_ref` + `report_brief.md`；冲突各方写明原话 | `evidence_labels.py`、`risk_reporter.py` |
| 高分与冲突并存需可解释 | 分数/置信分轴；置信标签「·冲突」 | `confidence_policy.json`、`risk_engine.py` |
| 不缩短对话、完整测评 | 保留 full 计划；不做早停/砍题 | `interview_policy.json`（未改时长策略） |
| 交接文档体例 | 交接七段结构 + 本追踪表 + 修改说明 | `PROJECT_HANDOVER_v0.6.1.md`、本文件、`V0.6.1_CHANGELOG_SCALE_REPORT.md` |
