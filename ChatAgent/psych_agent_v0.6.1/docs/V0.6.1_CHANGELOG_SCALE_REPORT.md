# 修改说明：量表约束与双版本可读报告

## 追加：锚定包 olweus_dbvs_bpbq_v1

将 Olweus 卷入切点、DBVS 形式维、BPBQ 旁观构念的**计分思想**写入 `docs/SCALE_RULES_SOURCE.md`，并落到 `scale_constraints` / `risk_scoring` / `variable_scoring` 与 `scale_gates.py`。  
续：冲突原因与证据原文写入报告；冲突不降风险分权重；角色工程置信带「·冲突」标签。终版样例：`outputs/recompute_69db8d61/`。

---

配置集合仍为 `CFG_008` / `0.6.1`（本轮为同版本功能增强，未另开 config_set）。

## 为何改

1. 将校园霸凌量表的构念思想（伤害性/持续、真实卷入 vs 纯假设）纳入评分门控，不推翻完整情境问答。
2. 为一线提供简洁报告；证据展示改为可读标签，避免正文出现 hash 地址。

| 区域 | 变更 |
