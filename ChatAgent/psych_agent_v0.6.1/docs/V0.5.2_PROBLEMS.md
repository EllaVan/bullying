# v0.5.2 问题诊断（基于代码 + 真人访谈 SESSION_f1cef6d66e10）

## 1. 覆盖≠程度：二值方向把强度压扁

- `variable_scoring.direction_values` 仅 `higher→1.0 / lower→0.0`。
- Facet 一旦“被覆盖”即满权计入，无法区分「想想而已」与「十分想打」。
- 真人报告中 PV03/PV05/PV06/PV07/PV09 多为 1.00，施暴相关被推到 **81.67 / 重点关注**，与“关系霸凌受害 + 旁观、程度并不极端”的临床印象不符。

## 2. 冲突处理与配置自相矛盾，且会抬高分数

- `evidence_quality.contradiction_policy` 写明 `retain_both_and_use_midpoint_for_test_score`。
- 实际 `facets.summarize`：冲突 → `status=conflict`、`value=None`，该面**退出分母**。
- 后果：冲突面被扔掉后，剩余少数非冲突面可把变量值拉到极端。例：PV05 两面 conflict，仅剩“群体责任”→ 变量值仍为 **1.00**（confidence 仅 0.33，但 A4 仍按 1.00 计风险支持）。
- 本次访谈至少 5 处 facet 冲突（PV05×2、PV06、PV10×2），两侧证据虽保留在 ledger，**不计分等于分析层丢弃**。

## 3. 冲突来源混杂，缺少分类与消解

实测冲突不全是“学生前后矛盾”，还包括：

| 类型 | 例子 |
| --- | --- |
| 疑似同句双命中 / 规则误触 | PV05 B05 两句都说“不太好”，却一 higher 一 lower |
| 对冲表述 | PV06 C02 同一假设回答同时抽到 higher/lower |
| 跨情境语境差 | PV10 E01 不同场景“不商量” vs “担心严重后果” |
| 规则语义可疑 | “太过分就该停止”被标为 PV05 higher（道德脱离↑），更像 lower |

0.5.2 对上述一律 `conflict` 剔除，无审计分类、无框架优先级、无澄清后改口策略。

## 4. 假设意向与真实经历等权

- `evidence_quality.eligible_reference_frames` 把假设、习惯、真实经历、一般信念一并纳入核心计分且**无框架降权**。
- 经历台账 `experience.json` 与风险分脱钩；本次真人访谈甚至 `no_validated_self_event`，无法支撑“受害/旁观”的经历证据层。

## 5. 角色体系缺旁观，结果被硬塞进三类

- A4 仅 `bully / victim / bully_victim`。
- 旁观相关线索（从众 PV07、道德脱离 PV05、共情 PV04、求助/干预 PV10）只能抬高施暴或受害相关分，**没有独立旁观通道**。
- `risk_profile_rules.json` 只是变量—角色关联清单，**不参与实际加权**；真正计分只看 `risk_scoring.json`。

## 6. 其它工程缺口（影响可信解释）

- A3 抽取错误（6 次 fallback）不回滚已写入的错误方向证据。
- 报告展示 Evidence ID，但对冲突两侧如何影响结论缺少专章。
- 阈值与权重未校准；confidence 是覆盖指标，易被误读为测量信度。

## 判定链路回顾（A3→报告）

1. A3 按规则命中 Evidence（方向由 rule 决定，非模型打分）。
2. `profile.build_profile` 按 unit×event×frame 分组 → Facet 汇总 → 变量 `value∈[0,1]`。
3. A4 按角色权重对 `risk_support`（风险变量=value，保护变量=1−value）加权 → 0–100 与 level。
4. A5 只解释，不改分数。

**结论**：偏重主要来自「有证据即满分」+「冲突面剔除导致剩余面极端化」+「无旁观角色」+「假设与真实等权」，而非单纯阈值偏紧。
