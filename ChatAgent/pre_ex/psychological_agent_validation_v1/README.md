# Psychological Agent Validation V1

校园欺凌心理Agent验证原型。

Pipeline:

Knowledge Layer
 -> Scenario Agent
 -> Interview Agent
 -> Evidence Agent
 -> Variable Agent
 -> Risk Agent

包含：
- 心理变量知识层
- 量表映射
- 情景驱动访谈
- Evidence抽取
- 心理变量融合
- 风险推理
- Evaluation框架

运行:
1. pip install -r requirements.txt
2. 配置 .env
3. python main.py
